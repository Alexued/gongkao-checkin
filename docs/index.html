每天

打卡这件事，做到不用想

任务与步骤

可以只打一个勾，也可以设数量目标（20 题、1 篇），或者拆成几步逐条勾掉。

  • 拆了步骤的任务，勾完最后一步自动完成
  • 没做完的量第二天自动结转，显示欠了几天
  • 长按任务卡直接编辑、开始专注、调顺序或删除

学习概览

一张建议卡只说一件事：先补最早的欠账，还是先做没完成的那条。

  • 当日事项、专注时长、复盘条数一屏看完
  • 行测 / 申论 双轨进度，按任务标题自动分
  • 点建议卡的按钮直接跳到该去的页面

日历与统计

热力图看哪天断了档，连续全勤和完成率都在同一屏。

  • 长按某天标记考试日，首页显示倒计时
  • 近两周完成率柱状图、最近 12 次计时对比
  • 点某天看当天做过的全部记录

练习

分步讲解

选完立即判对错，然后一步步展开讲解：每步划掉被排除的选项、高亮该看的数字，最后落到正确答案。

成套做题

自己定每次抽几题，左右滑动切上下题。答题卡看哪些做了哪些没做，点题号直接跳。

  • 做到一半退出可以存档，之后「继续做题」接着做
  • 每次做完都记一条，能回头看当时选了什么

背诵与速算

百化分、资料分析公式、18 种速算技巧，讲解回顾式：先自己想，再翻开对照，自评记住还是模糊。

专注计时

秒表分段打点，记录每道题用时。另有番茄钟，25 / 5 / 15 分钟，四轮后长休息。

两种用法

不备考的时候，它就是个习惯打卡

通用模式

在设置里一键切换。界面措辞和统计口径跟着变，背诵训练收起来， 但任务、打卡、计时、训练记录一条都不会动，切回考公模式原样都在。

同步与备份

两台手机之间直接传，不经过任何服务器。

  • 同一个 Wi-Fi 下搜索附近设备，整份收发
  • 用访问码或扫二维码确认，接收方要再确认一次才会覆盖

关于数据

所有记录都写在手机本地。没有账号，没有埋点，没有广告，也没有任何一次 把你的数据往外发的请求。同步只在你自己的局域网里发生， 只有检查更新时才会访问 GitHub。源码是公开的，可以自己核对。
