考公打卡
专注考公备考无广告数据不出内网开源

备考最难的不是某一天做多少题，而是明天还愿意再打开一次。这个 app 只做一件事：把今天该做的事摆在眼前，做完划掉。

清单

划掉的任务留在原位，不会被扔到列表最后 —— 位置变了，眼睛就得重新找一遍。长按任务从原处展开小卡片，改完缩回去。

背诵

百化分与资料分析公式各有全量、随机两种模式。成绩落库，错的下次还会遇到。公式按分类抽，认识与不认识分开计。

统计

月历热力图。颜色深浅是当天完成量，左右滑动换月。看的不是某天多努力，是这一片有没有断。

同步

手机起一个局域网 HTTP 服务，电脑浏览器打开就能改清单。同步开关随时能关，不想开的时候一条数据都不出去。

更新

应用内检查更新走两条通道：GitHub Release，或者局域网里版本更高的那台设备。下载完校验 SHA-256 再装。

  1. 06:40 · 起
    今天要做什么

    打开就是今日清单，不用点第二下。任务按自己的顺序排，完成后划掉，位置不动。

    划掉不重排 —— 位置一变，眼睛就得重新找一遍。
  2. 09:00 · 练
    计时器跑起来

    资料分析限时 20 分钟。倒计时开着，锁屏也在走，前台服务保证不被系统掐掉。

  3. 12:30 · 背
