# 考公打卡

公务员考试备考的每日打卡工具。原生 Android（Views + XML，非 Compose），离线可用，数据只存在手机本地。

## 功能

- **打卡** — 每日任务清单，可设数量目标或拆成步骤，未完成自动结转为次日欠账，长按任务直接改，可拖动调顺序
- **计时** — 秒表 + 打点，记录每道题用时；另有番茄钟（25 / 5 / 15 分钟）
- **背诵** — 百化分（24 组，等值分数自动判对）、资料分析公式（36 条，8 个分类）、18 种速算技巧
- **资料分析复盘** — 65 道精选真题（分步讲解）+ 1175 题真题题库，可自定题量、答题卡跳题、做一半存档续做
- **概览** — 一张建议卡指出下一步该做什么，行测 / 申论 双轨进度
- **统计** — 日历热力图、近两周完成率、做题用时对比、按天回看
- **设备直连同步** — 同一 Wi-Fi 下两台手机整份收发，访问码或扫码确认，不经过任何服务器
- **四套主题** — 白色 / 黑色 / 高斯模糊 / 液态玻璃，卡片一律不透明白；后两套是纯白页面 + 描边卡片，「玻璃」体现在长按浮层的真实窗口模糊上
- **通用模式** — 不备考时当习惯打卡用，收起备考训练但记录全留

## 构建

```bash
./gradlew assembleDebug
```

正式包需要签名密钥。本地把 `gongkao-release.jks` 放到仓库上一级目录，或用环境变量指定：

```bash
KEYSTORE_PATH=/path/to/gongkao-release.jks \
KEYSTORE_PASSWORD=... KEY_ALIAS=... KEY_PASSWORD=... \
./gradlew assembleRelease
```

找不到 keystore 时会回落到 debug 签名并给出警告 —— 这种产物**不能**用于线上更新（签名不一致装不上）。

## 版本

`versionCode` / `versionName` 可由环境变量 `VERSION_CODE` / `VERSION_NAME` 覆盖，CI 打 tag 时自动推导。

## 环境

- JDK 21
- compileSdk 36 / minSdk 26 / targetSdk 36
